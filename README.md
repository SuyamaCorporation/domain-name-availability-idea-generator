## Domain Name Availability Idea Generator

Generates 20–50 domain name ideas from 1–3 keywords using five strategies: direct (raw keyword), camelCase compound, abbreviation (first letters/truncation), prefix (get/my/use/go/try/the…), and suffix (app/io/hq/ly/hub/lab…). Results are displayed in a table with .com/.io/.app/.co extension columns for quick scanning. Each row has a copy-to-clipboard button. Filter buttons let you narrow results by strategy type.

**Tech:** Vanilla JS, Clipboard API, Tailwind CSS CDN. No DNS lookup — purely generative.  
**Usage:** Enter 1–3 keywords and click Generate (or press Enter). Use filter buttons to browse by name style.
